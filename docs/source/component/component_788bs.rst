LEDドットマトリックス
==========================

|img_led_matrix|

一般的に、LEDドットマトリックスは共通カソード（CC）と共通アノード（CA）の2つのタイプに分類されます。
外見は似ていますが、内部的な違いがあります。テストによって判断することができます。このキットでは、
CAタイプが使用されています。側面に788BSとラベル付けされています。

下図を参照してください。ピンは背面の両端に配置されています。ラベル側を基準にすると、この端のピンが1-8ピン、
もう一方が9-16ピンです。

外部ビュー：

|img_788bs_i|

以下の図はその内部構造を示しています。CA LEDドットマトリックスでは、ROWがLEDのアノードを表し、COLがカソードを表します。
CCタイプではこれが逆です。共通点：両タイプとも、ピン13、3、4、10、6、11、15、および16はすべてCOLで、ピン9、14、8、12、
1、7、2、および5はすべてROWです。左上の最初のLEDを点灯させたい場合、CA LEDドットマトリックスではピン9をHighに、ピン13
をLowに設定します。CCタイプでは、ピン13をHighに、ピン9をLowに設定します。最初の列全体を点灯させたい場合、CAではピン13を
Lowに設定し、ROWの9、14、8、12、1、7、2、5をHighに設定します。CCでは、ピン13をHighに設定し、ROWの9、14、8、12、1、7、2、5
をLowに設定します。より良い理解のために、以下の図を参照してください。

内部ビュー：

|img_788bs_sche|

上記の行と列に対応するピン番号：

=========== ====== ====== ===== ====== ===== ====== ====== ======
**COL**     **1**  **2**  **3** **4**  **5** **6**  **7**  **8**
**Pin No.** **13** **3**  **4** **10** **6** **11** **15** **16**
**ROW**     **1**  **2**  **3** **4**  **5** **6**  **7**  **8**
**Pin No.** **9**  **14** **8** **12** **1** **7**  **2**  **5**
=========== ====== ====== ===== ====== ===== ====== ====== ======

さらに、ここでは2つの74HC595チップが使用されています。1つはLEDドットマトリックスの行を制御し、
もう1つは列を制御します。
