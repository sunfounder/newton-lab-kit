マイクロスイッチ
========================

|img_micro_switch|

マイクロスイッチの構造は非常にシンプルです。スイッチの主要部品は以下の通りです：

|img_micro_switch2|

* 1.押しボタン（アクチュエータ）
* 2.カバー
* 3.動く部品
* 4.支持部
* 5.ケース
* 6.NO端子：通常開
* 7.NC端子：通常閉
* 8.接点
* 9.動くアーム

マイクロスイッチが物体に物理的に接触すると、その接点は位置を変えます。基本的な動作原理は以下の通りです。

プランジャーが解放された状態または休息位置にあるとき：

* 通常閉回路は電流を通すことができます。
* 通常開回路は電気的に絶縁されています。

プランジャーが押下されたりスイッチされたりするとき：

* 通常閉回路は開かれます。
* 通常開回路は閉じます。
