フォトレジスター
==================

|img_photoresistor|

フォトレジスターまたは光電セルは、光に応じて変化する可変抵抗器です。
フォトレジスターの抵抗値は、入射光の強度が増加すると減少し、光導電性を示します。

フォトレジスターは、光感知ディテクタ回路や、光を受けて動作するスイッチング回路の抵抗半導体として利用されます。暗闇では、フォトレジスターの抵抗値は数メガオーム（MΩ）に達することがありますが、光が当たると数百オームまで低下することがあります。
