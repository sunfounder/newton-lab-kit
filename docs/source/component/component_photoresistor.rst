Fotowiderstand
=================

|img_photoresistor|

Ein Fotowiderstand oder eine Fotozelle ist ein lichtgesteuerter variabler Widerstand.
Der Widerstand eines Fotowiderstands nimmt mit zunehmender Lichtintensität ab; mit anderen Worten, er zeigt Photoelektrizität.

Ein Fotowiderstand kann in lichtempfindlichen Detektorschaltungen sowie in licht- und dunkelaktivierten Schaltkreisen als Halbleiterwiderstand verwendet werden. Im Dunkeln kann der Widerstand eines Fotowiderstands bis zu mehreren Megaohm (MΩ) betragen, während er im Hellen so niedrig wie einige hundert Ohm sein kann.

Hier ist das elektronische Symbol des Fotowiderstands.
