リードスイッチ
======================

|img_reed|

リードスイッチは、適用された磁場によって操作される電気スイッチです。1936年にベル電話研究所のウォルター・B・エルウッドによって発明され、1940年6月27日に米国特許番号2264746で特許を取得しました。

リードスイッチの動作原理は非常にシンプルです。端で重なる2枚のリード（通常は鉄とニッケルの2つの金属製）が、小さな隙間（数マイクロン程度）で分離された状態でガラス管内に密封されています。ガラス管は高純度の不活性ガス（例えば窒素）で満たされており、一部のリードスイッチは高電圧性能を向上させるために内部に真空を持たせて作られています。

リードは磁束伝導体として機能します。運転していない時は2枚のリードは接触していませんが、永久磁石または電磁コイルによって生成された磁場を通過すると、適用された磁場がリードの端点近くで異なる極性を引き起こし、磁力がリード自体のバネ力を超えると、2枚のリードが引き合って回路を導通します。磁場が弱まったり消失したりすると、リードは自身の弾力性により解放され、接触面が分離して回路が開かれます。
