1.4 Bibliotheken installieren (Wichtig)
=========================================

Viele Bibliotheken sind direkt über den **Bibliotheks-Manager** der Arduino-IDE verfügbar. Sie können den **Bibliotheks-Manager** wie folgt aufrufen:

Im **Bibliotheks-Manager** können Sie entweder gezielt nach einer Bibliothek suchen oder verschiedene Kategorien durchsuchen.

.. note::

   In Projekten, die eine Bibliotheksinstallation erfordern, gibt es entsprechende Hinweise, welche Bibliotheken installiert werden müssen. Folgen Sie den Anweisungen, beispielsweise: 
   „Die DHT-Sensorbibliothek wird hier verwendet, Sie können sie über den Bibliotheks-Manager installieren.“ 
   Installieren Sie einfach die empfohlenen Bibliotheken gemäß den Anweisungen.

.. image:: img/install_lib3.png

Sobald Sie die gewünschte Bibliothek gefunden haben, klicken Sie darauf und anschließend auf den INSTALLIEREN-Button.

.. image:: img/install_lib2.png

Die Arduino-IDE lädt die Bibliothek automatisch herunter und installiert sie für Sie.


.. note::

   Die installierten Bibliotheken befinden sich im Standardbibliotheksverzeichnis der Arduino-IDE, das sich in der Regel unter ``C:\Users\xxx\Documents\Arduino\libraries`` befindet.

   Falls Ihr Bibliotheksverzeichnis abweicht, können Sie dies überprüfen, indem Sie zu **Datei** -> **Einstellungen** navigieren.

      .. image:: img/install_lib1.png
