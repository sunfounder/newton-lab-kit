コードのダウンロード
===========================

このキットの完全なコードパッケージを以下のリンクからダウンロードできます：

* :download:`SunFounder Newton Lab Kit Example <https://github.com/sunfounder/newton-lab-kit/archive/refs/heads/main.zip>`

* または、GitHubでコードを確認できます： `Newton Lab Kit - GitHub <https://github.com/sunfounder/newton-lab-kit>`_

ダウンロードが完了したら、ファイルを解凍し、対応するソフトウェアで関連するサンプルコードやプロジェクトファイルを開いてください。これにより、キットに含まれるすべてのコードやリソースを自由に閲覧・活用できます。
