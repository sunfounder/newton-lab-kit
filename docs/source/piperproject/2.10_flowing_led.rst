2.10 Fließende LEDs
======================

**Den Code schreiben**


.. note::

    * Sie können sich das untenstehende Bild ansehen, um den Code per Drag-and-Drop zu schreiben.
    * Importieren Sie ``2.10_flowing_led.png`` aus dem Pfad ``kepler-kit-main\piper``. Für detaillierte Tutorials siehe :ref:`import_code_piper`.

|neopixel|

Nachdem Sie Pico W angeschlossen haben, klicken Sie auf den **Start**-Button und der Code beginnt zu laufen.

Wenn der Neigungsschalter senkrecht platziert wird, leuchten die LEDs auf dem WS2812 RGB-LED-Streifen nacheinander in Grün auf, und wenn der Neigungsschalter waagerecht platziert wird, leuchten die LEDs in der entgegengesetzten Richtung nacheinander in Grün auf.



**Programmierung**


**Schritt 1**: Verwenden Sie den Block [setup neopixel pin() pixels()] in der **Actions**-Palette, um den WS2812 RGB-LED-Streifen zu initialisieren. **0** bedeutet, dass der verbundene Pin GP0 ist und **8** bedeutet, dass es 8 RGB-LEDs auf dem WS2812 RGB-LED-Streifen gibt.

|neo1|

**Schritt 2**: In der **Variables**-Palette klicken Sie auf den Button **Create variable**, um eine Variable namens **i** zu erstellen, die die LEDs auf dem WS2812 RGB-LED-Streifen repräsentiert.

|neo2|

**Schritt 3**: Setzen Sie den Anfangswert der Variablen **i** auf 1 (die LED in der Nähe der Drähte), dann verwenden Sie im Block [repeat forever] [() mod ()], um den Wert von i von 0 bis 7 einzustellen. z.B. 1 mod 8 = 1... 8 mod 8 =0, 9 mod 8 =1, usw.

* [() mod ()]: Dies ist der Modulo-Operator-Block, aus der **Loops**-Palette, klicken Sie auf [() = ()], um **mod** auszuwählen.

|neo3|

**Schritt 4**: Stellen Sie alle Neopixel auf Schwarz, um alle LEDs auszuschalten, dann verwenden Sie [updates neopixels], um diesen Effekt auf den WS2812 RGB-LED-Streifen zu übertragen.

|neo4|

* [set all neopixels to ()]: Wird verwendet, um eine Farbe für alle LEDs einzustellen, es gibt 13*9 Farben, die Farbe oben rechts ist Schwarz, um die LEDs auszuschalten.
* [updates neopixels]: Aktualisiert den Effekt auf den WS2812 RGB-LED-Streifen.

**Schritt 5**: Wenn Pin14 hoch gelesen wird, lassen Sie die LEDs auf dem WS2812 RGB-LED-Streifen nacheinander in Grün aufleuchten, sonst leuchten sie nacheinander in der entgegengesetzten Richtung in Grün auf.

|neo5|

* [change () by ()]: Wird verwendet, um den Wert einer Variablen um einen bestimmten Schritt zu erhöhen (positiv) oder zu verringern (negativ).
