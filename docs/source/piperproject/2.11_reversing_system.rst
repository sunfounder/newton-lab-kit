2.11 バックアップ警報システム
==============================

このプロジェクトでは、超音波モジュールとアクティブブザーを使用してバックアップ警報システムを作成します。超音波モジュールは距離を検出し、距離に応じてブザーが異なる周波数の警告音を発します。

**配線**

|reversing_system0|


* 超音波モジュールのエコーとトリガーピンは同時にGP15に接続され、超音波モジュールがGP15から信号を送受信します。
* トランジスタの中央のピンは1kΩの抵抗を介してGP14に接続されます。

**コードの書き方**

.. note::

    * 以下の画像を参考にして、ドラッグアンドドロップでコードを書くことができます。
    * ``kepler-kit-main\piper`` のパスから ``2.11_reversing_system.png`` をインポートしてください。詳細なチュートリアルについては :ref:`import_code_piper` を参照してください。


|reversing_system|

* Pico Wに接続した後、 **Start** ボタンをクリックしてコードを実行します。
* 超音波検出距離が5cm未満の場合、ブザーが鋭い音（0.1s）を発します。
* 検出距離が5~10cmの場合、ブザーがやや遅い音（0.5s）を発します。
* 検出距離が10cmを超える場合、1秒ごとに音のプロンプトがあります。


**コードの理解**


|reversing_system1|

超音波検出の距離（cm）を読み取り、変数[distance]に格納します。

|reversing_system2|

距離が5以下の場合、変数[intervals]を0.1sに設定します。変数[intervals]はブザー音の間隔です。

|reversing_system3|

距離が5を超え、10以下の場合、[intervals]を0.5sに設定します。

|reversing_system4|

距離が10を超える場合、[intervals]の時間を1sに設定します。

|reversing_system5|

最後に、[intervals]秒ごとにブザーを鳴らします。
