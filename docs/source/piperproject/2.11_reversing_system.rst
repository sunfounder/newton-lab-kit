==========================

**Verkabelung**

|reversing_system0|


* Die Echo- und Trig-Pins des Ultraschallmoduls sind gleichzeitig mit GP15 verbunden, sodass das Ultraschallmodul Signale von GP15 sendet und empfängt.
* Der mittlere Pin des Transistors, der mit dem Summer verbunden ist, ist über einen 1kΩ Widerstand mit GP14 verbunden.

**Den Code schreiben**

.. note::

    * Sie können sich das untenstehende Bild ansehen, um den Code per Drag-and-Drop zu schreiben.
    * Importieren Sie ``2.11_reversing_system.png`` aus dem Pfad ``kepler-kit-main\piper``. Für detaillierte Tutorials siehe :ref:`import_code_piper`.


|reversing_system|

* Nachdem Sie Pico W angeschlossen haben, klicken Sie auf den **Start**-Button und der Code beginnt zu laufen.
* Wenn die Ultraschall-Erkennungsdistanz weniger als 5 cm beträgt, gibt der Summer einen scharfen Ton (0,1 s) aus.
* Wenn die Erkennungsdistanz zwischen 5~10 cm liegt, gibt der Summer einen etwas langsameren Ton (0,5 s) aus.
* Wenn die Erkennungsdistanz größer als 10 cm ist, gibt es alle 1 Sekunde einen Tonhinweis.


**Den Code verstehen**


|reversing_system1|

Lesen Sie die Entfernung (in cm) der Ultraschallerkennung und speichern Sie sie in der Variablen [distance].

|reversing_system2|

Wenn die Entfernung kleiner oder gleich 5 ist, setzen Sie die Variable Intervalle auf 0,1 s. Die Variable [intervals] ist das Intervall zwischen den Summerklängen.

|reversing_system3|

Wenn die Entfernung größer als 5 und kleiner oder gleich 10 ist, setzen Sie die [intervals] auf 0,5 s.

|reversing_system4|

Wenn die Entfernung größer als 10 ist, setzen Sie die [intervals] Zeit auf 1 s.

|reversing_system5|

Lassen Sie den Summer schließlich alle [intervals] Sekunden ertönen.
