|temperature_controlled_fan|

* Pico Wに接続した後、 **Start** ボタンをクリックしてコードを実行します。
* CONSLEをクリックすると、現在の温度が摂氏で表示されます。
* 温度が25度以上の場合、ファンが回転を始め、25度未満の場合は回転を停止します。

.. note::

    * Stopボタンをクリックした後もモーターが回転し続ける場合は、この時にPico WのRunピンをワイヤーでGNDにリセットする必要があります。その後、このワイヤーを抜いて再度コードを実行してください。
    * これは、モーターが多くの電流を使用しているためで、これによりPico Wがコンピュータから切断される可能性があります。

**コードの理解**

|temperature_controlled_fan1|

A0（GP26）の電圧を読み取り、変数[Vr]に割り当てます。

|temperature_controlled_fan2|

これらの計算は、サーミスタの値を摂氏温度に変換します。


.. note::
    ここでの抵抗と温度の関係は次のとおりです：

    **RT = RN expB(1/TK – 1/TN)** 

    * RTは、温度がTKのときのNTCサーミスタの抵抗値です。
    * RNは、定格温度TNの下でのNTCサーミスタの抵抗値です。ここでは、RNの数値は10kです。
    * TKはケルビン温度で、単位はKです。ここでは、TKの数値は273.15 + 摂氏度です。
    * TNは定格ケルビン温度で、単位もKです。ここでは、TNの数値は273.15+25です。
    * B（ベータ）はNTCサーミスタの材料定数で、熱感度指数とも呼ばれ、数値は3950です。
    * expは指数関数の略で、基数eは自然数で、約2.7です。

    この式 **TK=1/(ln(RT/RN)/B+1/TN)** を変換してケルビン温度を求め、273.15を引くと摂氏度になります。

    この関係は経験式であり、温度と抵抗が効果的な範囲内にある場合にのみ正確です。


|temperature_controlled_fan5|

温度が25度以上の場合、GP14をON、GP15をOFFに設定してモーターを回転させます。または、そのレベルを逆にすることができます。温度が25度未満の場合、GP14とGP15を両方とも低く設定してモーターを停止させます。
