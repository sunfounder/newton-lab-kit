2.13 リアクションゲーム
===========================


ここでは、複数のボタン、ブザー、LEDを使用してリアクションゲームを作ります。審判のボタンを押してゲームを開始し、ブザーも鳴り続けてゲームが続いていることを示します。2人のプレイヤーボタンをそれぞれ素早く押し、審判のボタンが再度押されると、ゲームは終了しブザーも停止します。この時点でPiper MakeのCONSOLEを見ると、誰の手が早いかが分かります。

**配線**

|button_race0|

* GP14（player1）とGP12（player2）の2つのボタンを定義し、それぞれにプルアップ抵抗が接続されています。ボタンが押されると、GP14とGP12はそれぞれ低くなります。
* それぞれの指示器はGP15とGP13に接続され、高出力で点灯します。
* 審判のボタンはGP10に接続され、ボタンが押されるとGP10が低くなります。
* アクティブブザーはGP11に接続され、GP11が高出力の場合、ブザーが鳴ります。

**コードの書き方**

.. note::

    * 以下の画像を参考にして、ドラッグアンドドロップでコードを書くことができます。
    * ``kepler-kit-main\piper`` のパスから ``2.13_reaction_game.png`` をインポートしてください。詳細なチュートリアルについては :ref:`import_code_piper` を参照してください。


|button_race|

* Pico Wに接続した後、 **Start** ボタンをクリックしてコードを実行します。
* 審判のボタンを押すと、ブザーが鳴り始め（連続して）、ゲームが開始されます。
* この時点で **プレイヤー** ボタンを別々に素早く押し、対応するLEDが点灯します。
* **審判** ボタンが再び押されると、ブザーが停止し、ゲームが終了します。
* この時点でCONSOLEをクリックすると、誰がより多く押したかが表示されます。

**コードの理解**

|button_race1|


GP10は審判のボタンで、審判のボタンが押されていないときは高く、ゲームはまだ始まっていません。
GP10が低い（審判のボタンが押された場合）、ゲームが開始されます。GP11を高く設定し（ブザー）、変数を作成して初期値を設定します。

|button_race2|

ゲームが始まってflagが1の場合、GP14（player1）の値を読み取ります。player1ボタンが押された場合、押し回数を変数[count1]に保存し、GP15の指示器を点灯させます。


|button_race3|

同じようにGP12（player2）の押し回数を読み取ります。


|button_race4|

player1とplayer2の押し回数をそれぞれ印刷します。

|button_race5|

審判のボタンが再び押されると、ブザーが機能停止し、ゲームが終了します。
