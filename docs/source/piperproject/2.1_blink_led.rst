2.1 LEDの点滅
================

このプロジェクトでは、拡張LEDライトを点滅させることを目指します。拡張電子部品を使用する際、はんだ付け不要のブレッドボードは初心者にとって最も強力なパートナーとなります。

ブレッドボードは、小さな穴がたくさん開いた長方形のプラスチック板です。これらの穴には電子部品を簡単に差し込み、電子回路を構築できます。ブレッドボードは電子部品を永久に固定しないため、間違いを犯したときに回路を修理しやすく、やり直しやすくなっています。

**コードの理解**

これがループの本体です：pin15をONにしてLEDを点灯させ、1秒待ちます。次にpin15をOFFにしてLEDを消灯させます。1秒待ってから前のサイクルを再実行するので、LEDが点灯と消灯を交互に繰り返しているのがわかります。

* [start]: このブロックはプログラムの基本的な枠組みであり、プログラムの開始を表します。
* [repeat forever do() wait()seconds]: 内包されたブロックが繰り返し実行され、実行時間間隔は自分で定義します。
* [turn pin () ON/OFF]: 特定のピンを高レベル（ON）または低レベル（OFF）に設定します。
* [wait () seconds]: ブロック間の実行間隔を設定します。
