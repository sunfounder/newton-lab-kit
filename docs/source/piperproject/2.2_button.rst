**Verkabelung**


|button0|


* Ein Pin des Schalters ist mit 3.3V verbunden, der andere Pin mit GP14, sodass, wenn der Schalter gedrückt wird, GP14 hoch ist. 
* Wenn der Schalter jedoch nicht gedrückt wird, befindet sich GP14 in einem Schwebezustand und kann hoch oder niedrig sein. Um einen stabilen niedrigen Pegel zu erreichen, wenn der Schalter nicht gedrückt wird, muss GP14 über einen 10K Pull-Down-Widerstand erneut mit GND verbunden werden.


**Den Code schreiben**

.. note::

    * Sie können sich das untenstehende Bild ansehen, um den Code per Drag-and-Drop zu schreiben.
    * Importieren Sie ``2.2_button.png`` aus dem Pfad ``kepler-kit-main\piper``. Für detaillierte Tutorials siehe :ref:`import_code_piper`.


|2.2_button|

Nachdem Sie Pico W angeschlossen haben, klicken Sie auf den **Start**-Button und der Code beginnt zu laufen. Wenn der Schalter gedrückt wird, leuchtet die LED. Wenn der Schalter losgelassen wird, erlischt die LED.


**Den Code verstehen**

Wenn der Schalter gedrückt wird, ist Pin14 hoch. Also, wenn Pin14 hoch gelesen wird, schalte Pin15 ein (LED leuchtet); sonst, schalte Pin15 aus (LED ist aus).

* [if () do () else ()]: Dies ist ein Urteilsblock, der abhängig von der Bedingung nach dem [if]-Block entscheidet, ob die Blöcke im [do]-Block oder die Blöcke im [else]-Block ausgeführt werden.
* [is pin () HIGH]: Dies wird verwendet, um den Pegel eines spezifischen Pins zu lesen, wenn der gelesene Pegel mit dem eingestellten HIGH/LOW übereinstimmt, dann führe die Blöcke im [do]-Block aus, sonst die im [else].
