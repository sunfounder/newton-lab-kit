**配線**


|button0|

* ボタンの片側のピンは3.3Vに接続され、もう片側のピンはGP14に接続されているため、ボタンが押されるとGP14は高電圧になります。
* ただし、ボタンが押されていないときは、GP14は浮いた状態であり、高いか低いかが不安定です。ボタンが押されていないときに安定した低レベルを得るために、GP14は10Kのプルダウン抵抗を介してGNDに再接続する必要があります。


**コードの書き方**

.. note::

    * 以下の画像を参照して、ドラッグアンドドロップでコードを書くことができます。
    * ``kepler-kit-main\piper`` のパスから ``2.2_button.png`` をインポートしてください。詳細なチュートリアルについては :ref:`import_code_piper` を参照してください。


|2.2_button|

Pico Wに接続した後、 **Start** ボタンをクリックするとコードが実行されます。ボタンを押すとLEDが点灯し、ボタンを離すとLEDが消えます。


**コードの理解**

ボタンが押されると、pin14は高い状態になります。したがって、pin14が高い状態であることを読み取れば、pin15をオンにして(LEDを点灯させ)、そうでなければpin15をオフにします(LEDを消灯させます)。

* [if () do () else ()]: これは条件判断のブロックで、[if] ブロック後の条件によって [do] ブロック内か [else] ブロック内のブロックを実行するかを決定します。
* [is pin () HIGH]: 特定のピンのレベルを読み取るために使用され、読み取ったレベルが設定されたHIGH/LOWと同じであれば [do] ブロック内のブロックを実行し、そうでなければ [else] 内のブロックを実行します。
