2.3 コールベル
==========================

このプロジェクトでは、マイクロスイッチとアクティブブザーを使用してサービスベルを作成します。スイッチをタップすると、ブザーが音を出します。

マイクロスイッチも3ピンのデバイスで、3つのピンの順序はC（コモンピン）、NO（ノーマリーオープン）、NC（ノーマリークローズド）です。

マイクロスイッチが押されていないとき、1（C）と3（NC）が接続されています。押されたときは、1（C）と2（NO）が接続されます。

**配線**

|service_bell0|

* デフォルトでは、マイクロスイッチのピン1と3が接続されており、GP14は低電圧です。マイクロスイッチが押されると、GP14は高電圧になります。
* GP15が高電圧を出力してブザーを鳴らします。
