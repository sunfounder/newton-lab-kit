2.4 Regenbogenlicht
======================

In diesem Projekt werden wir RGB-LEDs dazu bringen, ein Farbspektrum wie ein Regenbogen anzuzeigen.

Eine RGB-LED entspricht einer Kapselung von roter, grüner und blauer LED unter einer Lampenabdeckung, wobei die drei LEDs einen gemeinsamen Kathodenpin teilen. Da jedem Anodenpin ein elektrisches Signal zugeführt wird, kann das Licht der entsprechenden Farbe angezeigt werden. Durch Ändern der Signalintensität jeder Anode können verschiedene Farben erzeugt werden.

**Verkabelung**

|img_rgb_pin|

Eine RGB-LED hat 4 Pins: Der längste Pin ist der gemeinsame Kathodenpin, der normalerweise mit GND verbunden ist, der linke Pin neben dem längsten Pin ist Rot, und die 2 Pins rechts sind Grün und Blau.

|rgb0|


* Wenn dieselbe Stromversorgungsintensität verwendet wird, leuchtet die rote LED heller als die anderen beiden, und es muss ein etwas größerer Widerstand (330Ω) verwendet werden, um ihre Helligkeit zu reduzieren.
* Die 3 Tasten werden verwendet, um das Leuchten der roten, grünen und blauen LEDs jeweils zu steuern. 

**Den Code schreiben**

.. note::

    * Sie können sich das untenstehende Bild ansehen, um den Code per Drag-and-Drop zu schreiben.
    * Importieren Sie ``2.4_rainbow_light.png`` aus dem Pfad ``kepler-kit-main\piper``. Für detaillierte Tutorials siehe :ref:`import_code_piper`.

|rgb_led|

Nachdem Sie Pico W angeschlossen haben, klicken Sie auf den **Start**-Button und der Code beginnt zu laufen. Wenn diese Tasten einzeln gedrückt werden, wird jeweils eine einzelne Farbe emittiert, aber wenn zwei der Tasten gleichzeitig gedrückt werden, oder alle 3 Tasten gleichzeitig gedrückt werden, emittieren die RGB-LEDs eine Vielzahl verschiedener Farben, bis zu einem Maximum von 7.

.. note::
    Tatsächlich können RGB-LEDs bis zu 16 Millionen Farben emittieren, aber da Piper Make keinen Block hat, um ein PWM-Signal auszugeben, verwenden wir hier nur den [turn pin() (ON/OFF)] Block, damit die RGB-LEDs 7 Farben anzeigen.

**Den Code verstehen**

Sie können sich dieses Projekt so vorstellen, dass drei Tasten verwendet werden, um die RGB-LED zu steuern, wobei drei If-Bedingungen gesetzt werden, um zu bestimmen, ob die drei Tasten gedrückt sind oder nicht.
Wenn die Tasten gedrückt werden, werden die Pegel der entsprechenden Pins hochgezogen, was dazu führt, dass die RGB-LED verschiedene Farben anzeigt.
