**Verkabelung**

|drum_kit0|

* Wenn der Schiebeschalter nach rechts umgelegt wird, ist GP12 hoch; wenn nach links umgelegt, ist GP12 niedrig.
* Jeder der drei Tasten ist mit einem Pull-Down-Widerstand verbunden, GP13~GP15 sind standardmäßig niedrig; wenn die Taste gedrückt wird, sind GP13~GP15 hoch.


**Den Code schreiben**

.. note::

    * Sie können sich das untenstehende Bild ansehen, um den Code per Drag-and-Drop zu schreiben.
    * Importieren Sie ``2.5_drum_kit.png`` aus dem Pfad ``kepler-kit-main\piper``. Für detaillierte Tutorials siehe :ref:`import_code_piper`.


|drum_kit|

Nachdem Sie Pico W angeschlossen haben, klicken Sie auf den **Start**-Button und der Code beginnt zu laufen. Durch Drücken verschiedener Tasten oder Umlegen des Schiebeschalters werden verschiedene Schlagzeugklänge erzeugt, genau wie bei einem Schlagzeug-Set.

.. note::
    Wenn Sie einen Computer verwenden, müssen Sie Kopfhörer oder Audio an Ihren Computer anschließen, um den erzeugten Klang zu hören.
