**配線**

|drum_kit0|

* スライドスイッチが右に切り替えられると、GP12は高い状態になります。左に切り替えられると、GP12は低い状態になります。
* 3つのボタンはそれぞれプルダウン抵抗に接続され、デフォルトではGP13〜GP15は低い状態です。ボタンが押されると、GP13〜GP15は高い状態になります。


**コードの書き方**

.. note::

    * 以下の画像を参考にして、ドラッグアンドドロップでコードを書くことができます。
    * ``kepler-kit-main\piper`` のパスから ``2.5_drum_kit.png`` をインポートしてください。詳細なチュートリアルについては :ref:`import_code_piper` を参照してください。


|drum_kit|

Pico Wに接続した後、 **Start** ボタンをクリックするとコードが実行されます。異なるボタンを押すかスライドスイッチを切り替えることで、ドラムキットのようにさまざまなドラムサウンドが生成されます。

.. note::
    コンピュータを使用している場合は、発生した音を聞くためにコンピュータにヘッドフォンまたはオーディオを接続する必要があります。
