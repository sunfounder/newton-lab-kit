**配線**

|pin_adc|

Pico Wはアナログ入力を使用できるGPIOピンがGP26, GP27, GP28の3つあります。これらはアナログチャネル0、1、2です。
さらに、内蔵の温度センサーに接続された4番目のアナログチャネルがありますが、ここでは紹介しません。

|water_tank0|

* 水位センサーのSはGP26（A0）に接続され、+はVBUSに、-ピンはGNDに接続されます。
* サーボのオレンジ色のワイヤー（シグナル）はGP15に接続され、赤色のワイヤー（電力）はVBUSに、茶色のワイヤー（グラウンド）はGNDに接続されます。

**コードの書き方**

.. note::

    * 以下の画像を参考にして、ドラッグアンドドロップでコードを書くことができます。
    * ``kepler-kit-main\piper`` のパスから ``2.6_water_tank.png`` をインポートしてください。詳細なチュートリアルについては :ref:`import_code_piper` を参照してください。

|water_tank|



Pico Wに接続した後、 **Start** ボタンをクリックするとコードが実行されます。水位センサーの水位が1/3未満の場合、サーボは180度回転して入口が開くことをシミュレートします。水位が水位センサーの1/3を超えると、サーボは0度に回転して入口が閉じることを模倣します。

**コードの理解**

|water_tank1|

pin15（サーボ）の回転速度を15％に設定します。

* [servo pin() set speed to ()%]: サーボピンの回転速度を設定するために使用され、範囲は0%〜100%です。

|water_tank2|

ピンA0の値を読み取り、変数[water_level]に格納します。

* [set (water_level) to]: 変数の値を設定するために使用され、変数は **Variables** パレットから作成する必要があります。
* [read voltage from pin ()]: アナログピン（A0〜A2）の電圧を読み取るために使用され、範囲は0〜3.3Vです。

|water_tank3|

電圧のしきい値を1に設定します。水位センサーの電圧が1未満の場合はサーボを180°位置に回転させ、それ以外の場合は0°位置に回転させます。

* [servo pin () set angle to ()]: サーボピンの角度を設定します。範囲は0〜180°です。
