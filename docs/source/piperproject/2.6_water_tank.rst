2.6 Intelligenter Wassertank
================================

In diesem Projekt verwenden wir einen Wasserstandssensor und ein Servo, um einen intelligenten Wassertank zu simulieren. Der Wasserstandssensor ist innerhalb des Tanks angebracht, um den Wasserstand zu messen, und wenn der Wasserstand unter einen Schwellenwert fällt, wird das durch das Servo gesteuerte Ventil geöffnet, um Wasser einzulassen.

**Verkabelung**

|pin_adc|

Der Pico W verfügt über drei GPIO-Pins, die für analoge Eingaben verwendet werden können: GP26, GP27, GP28. Das sind die analogen Kanäle 0, 1 und 2.
Außerdem gibt es einen vierten analogen Kanal, der mit dem eingebauten Temperatursensor verbunden ist und hier nicht weiter erläutert wird.


|water_tank0|

* S des Wasserstandssensors ist mit GP26(A0) verbunden, + mit VBUS, - Pin mit GND.
* Das orangefarbene Kabel (Signal) des Servos ist mit GP15 verbunden, das rote Kabel (Strom) mit VBUS und das braune Kabel (Masse) mit GND. 

**Den Code schreiben**

.. note::

    * Sie können sich das untenstehende Bild ansehen, um den Code per Drag-and-Drop zu schreiben.
    * Importieren Sie ``2.6_water_tank.png`` aus dem Pfad ``kepler-kit-main\piper``. Für detaillierte Tutorials siehe :ref:`import_code_piper`.

|water_tank|



Nachdem Sie Pico W angeschlossen haben, klicken Sie auf den **Start**-Button und der Code beginnt zu laufen. Wenn der Wasserstand unter 1/3 des Wasserstandssensors liegt, dreht sich das Servo auf 180 Grad, um die Einfüllöffnung zu simulieren; wenn der Wasserstand über 1/3 des Wasserstandssensors liegt, dreht sich das Servo auf 0 Grad, um die Einfüllöffnung zu schließen.

**Den Code verstehen**

|water_tank1|

Die Drehgeschwindigkeit von Pin15 (Servo) auf 15% einstellen.

* [servo pin() set speed to ()%]: Wird verwendet, um die Drehgeschwindigkeit des Servo-Pins einzustellen, der Bereich liegt zwischen 0% und 100%.

|water_tank2|

Liest den Wert von Pin A0 und speichert ihn in der Variable [water_level].

* [set (water_level) to]: Wird verwendet, um den Wert der Variablen einzustellen, Sie müssen die Variable aus der **Variablen**-Palette erstellen.
* [read voltage from pin ()]: Wird verwendet, um die Spannung der analogen Pins (A0~A2) zu lesen, der Bereich liegt zwischen 0 und 3.3V.

|water_tank3|

Die Spannungsschwelle auf 1 setzen. Wenn die Spannung des Wasserstandssensors weniger als 1 beträgt, lässt das Servo den Winkel auf 180° drehen, ansonsten auf 0°.

* [servo pin () set angle to ()]: Stellt den Winkel des Servo-Pins ein, der Bereich liegt zwischen 0 und 180°.
