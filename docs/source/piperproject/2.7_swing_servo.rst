**Verkabelung**

|controllable_servo0|


* Das orangefarbene Kabel (Signal) des Servos ist mit GP15 verbunden, das rote Kabel (Strom) mit VBUS und das braune Kabel (Masse) mit GND. 
* Das Potentiometer ist ein resistives Element mit 3 Anschlüssen, die beiden seitlichen Pins sind mit 5V und GND verbunden, und der mittlere Pin ist mit GP26(A0) verbunden.

**Den Code schreiben**

.. note::

    * Sie können sich das untenstehende Bild ansehen, um den Code per Drag-and-Drop zu schreiben.
    * Importieren Sie ``2.7_swing_servo.png`` aus dem Pfad ``kepler-kit-main\piper``. Für detaillierte Tutorials siehe :ref:`import_code_piper`.

|controllable_servo|

* Nachdem Sie Pico W angeschlossen haben, klicken Sie auf den **Start**-Button und der Code beginnt zu laufen.
* Drehen Sie das Potentiometer, und das Servo wird folgen. Um dies klar zu sehen, können Sie einen Hebel in die Servoachse einsetzen.

**Den Code verstehen**

|controllable_servo1|

Die Drehgeschwindigkeit von Pin15 (Servo) auf 15% einstellen.

* [servo pin() set speed to ()%]: Wird verwendet, um die Drehgeschwindigkeit des Servo-Pins einzustellen, der Bereich ist 0%~100%.

|controllable_servo2|

Erstellen Sie eine Variable [Winkel], lesen Sie dann die Spannung von A0. Verwenden Sie den Block [Wert () von () bis () umwandeln], um die Spannung von A0 von 0 bis 3,3V auf 0 bis 180° umzuwandeln, und verwenden Sie dann den umgewandelten Winkel als Drehwinkel des Servos.

* [Wert () von () bis () umwandeln]: mappt einen Wert von einem Bereich in einen anderen.

.. note::
    Die Spannung von A0~A2 nimmt den Bereich von 0~3,3V an, auch wenn Ihre Stromversorgung an VBUS (5V) angeschlossen ist.
