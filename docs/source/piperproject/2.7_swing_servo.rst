**配線**

|controllable_servo0|


* サーボのオレンジ色のワイヤー（シグナル）はGP15に接続され、赤色のワイヤー（電力）はVBUSに接続され、茶色のワイヤー（グラウンド）はGNDに接続されます。
* ポテンショメーターは3端子の抵抗素子で、両側の端子は5VとGNDに接続され、中央の端子はGP26（A0）に接続されます。

**コードの書き方**

.. note::

    * 以下の画像を参考にして、ドラッグアンドドロップでコードを書くことができます。
    * ``kepler-kit-main\piper`` のパスから ``2.7_swing_servo.png`` をインポートしてください。詳細なチュートリアルについては :ref:`import_code_piper` を参照してください。

|controllable_servo|

* Pico Wに接続した後、 **Start** ボタンをクリックするとコードが実行されます。
* ポテンショメーターを回すと、サーボもそれに応じて回転します。明確に見るために、サーボのシャフトにロッカーアームを挿入することができます。

**コードの理解**

|controllable_servo1|

pin15（サーボ）の回転速度を15％に設定します。

* [servo pin() set speed to ()%]: サーボピンの回転速度を設定するために使用され、範囲は0%〜100%です。

|controllable_servo2|

変数[angle]を作成し、A0の電圧を読み取ります。[map value () from () to ()]ブロックを使用し、A0の電圧を0から3.3Vの範囲から0から180°の範囲にマッピングし、その後マッピングされた角度をサーボの回転角度として使用します。

* [map value () from () to ()]: ある範囲の値を別の範囲にマッピングするために使用されます。

.. note::
    A0〜A2の電圧は0〜3.3Vの範囲を取りますが、電源がVBUS（5V）に接続されていてもその範囲です。
