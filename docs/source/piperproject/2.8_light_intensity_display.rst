**Verkabelung**

|light_intensity_display0|


* Die LED-Balkenanzeige besteht aus 10 LEDs, wobei die Seite mit der Beschriftung die Anode und die gegenüberliegende Seite die Kathode ist.
* Die Anoden der LED-Balkenanzeige sind mit GP6~GP15 verbunden. Die Kathoden sind mit einem 220-Ohm-Widerstand verbunden und dann mit GND.
* Ein Ende des Fotowiderstands wird mit 3,3V verbunden und das andere Ende mit GP26 (A0). Gleichzeitig muss GP26 mit einem weiteren 10K-Widerstand mit GND verbunden werden. Auf diese Weise erhöht sich die Spannung von A0, wenn das Licht stärker wird.


**Den Code schreiben**


.. note::

    * Sie können sich das untenstehende Bild ansehen, um den Code per Drag-and-Drop zu schreiben.
    * Importieren Sie ``2.8_light_intensity_display.png`` aus dem Pfad ``kepler-kit-main\piper``. Für detaillierte Tutorials siehe :ref:`import_code_piper`.

|light_intensity_display|

* Nachdem Sie Pico W angeschlossen haben, klicken Sie auf den **Start**-Button und der Code beginnt zu laufen.
* Wenn das Licht stärker ist, leuchten mehr LEDs auf der LED-Balkenanzeige. 
* Wenn der Code nicht richtig leuchtet, können Sie versuchen, die LED-Leiste umzudrehen.



**Den Code verstehen**

|light_intensity_display1|

Stellen Sie die Pins der LED-Balkenanzeige, die mit GP6 ~ GP15 verbunden sind, ein.


|light_intensity_display2|

Speichern Sie den Spannungswert von A0 (GP26), der in die Variable [photo_vol] eingelesen wird. Verwenden Sie den Block [Wert () von () bis () umwandeln], um die Variable [photo_vol] von 0 bis 3,3V auf 0 bis 10 (Anzahl der LEDs auf der LED-Balkenanzeige) umzuwandeln.

* [Wert () von () bis () umwandeln]: mappt einen Wert von einem Bereich in einen anderen.
