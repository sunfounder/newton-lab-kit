**配線**

|light_intensity_display0|

* LEDバーグラフは10個のLEDから構成されており、ラベル側がアノード、反対側がカソードです。
* LEDバーグラフのアノードはGP6〜GP15に接続され、カソードは220オームの抵抗器を介してGNDに接続されます。
* フォトレジスタの片端を3.3Vに、もう片端をGP26（A0）に接続します。同時に、GP26は別の10K抵抗器を介してGNDに接続する必要があります。これにより、光が強くなるとフォトレジスタの抵抗値が減少し、A0の電圧が上昇します。

**コードの書き方**

.. note::

    * 以下の画像を参考にして、ドラッグアンドドロップでコードを書くことができます。
    * ``kepler-kit-main\piper`` のパスから ``2.8_light_intensity_display.png`` をインポートしてください。詳細なチュートリアルについては :ref:`import_code_piper` を参照してください。

|light_intensity_display|

* Pico Wに接続した後、 **Start** ボタンをクリックするとコードが実行されます。
* 光が強くなると、LEDバーグラフのLEDがより多く点灯します。
* コードの実行が適切に行われない場合は、LEDバーを反転させてみてください。

**コードの理解**

|light_intensity_display1|


GP6〜GP15に接続されたLEDバーグラフのピンを設定します。

|light_intensity_display2|

A0 (GP26) から読み取った電圧値を変数 [photo_vol] に保存します。[map value () from () to ()] ブロックを使用して、変数 [photo_vol] を0から3.3Vの範囲から0から10（LEDバーグラフのLEDの数）の範囲にマッピングします。

* [map value () from () to ()]: 値を一つの範囲から別の範囲にマッピングするために使用します。
