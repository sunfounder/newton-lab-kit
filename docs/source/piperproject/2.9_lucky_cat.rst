**Verkabelung**

|lucky_cat0|


* Das orangefarbene Kabel (Signal) des Servos ist mit GP15 verbunden, das rote Kabel (Strom) mit VBUS und das braune Kabel (Masse) mit GND. 
* Der mittlere Pin des PIR-Moduls ist mit dem GP3 verbunden.

**Den Code schreiben**



.. note::

    * Sie können sich das untenstehende Bild ansehen, um den Code per Drag-and-Drop zu schreiben.
    * Importieren Sie ``2.9_lucky_cat.png`` aus dem Pfad ``kepler-kit-main\piper``. Für detaillierte Tutorials siehe :ref:`import_code_piper`.

|lucky_cat|



* Nachdem Sie Pico W angeschlossen haben, klicken Sie auf den **Start**-Button und der Code beginnt zu laufen.
* Wenn das PIR-Modul die Ankunft eines Kunden erkennt, schwingt das Servo fünfmal hin und her und stoppt dann.


**Den Code verstehen**


|lucky_cat1|

Die Drehgeschwindigkeit von Pin15 (Servo) auf 15% einstellen.

|lucky_cat2|

Wenn GP14 niedrig ist, setzen Sie die Variable [prestate] auf 0. Wenn die Variable [prestate] 0 ist und GP14 hoch ist (Mensch erkannt), setzen Sie die Variable [prestate] auf 1.

Der Zweck davon ist, dass der Hauptcode nur arbeitet, wenn der GP14 von niedrig auf hoch wechselt, und nur einmal reagiert, wenn das PIR-Modul weiterhin Menschen erkennt.

|lucky_cat3|

Das Servo zyklisch 5-mal von 0 bis 180 Grad drehen lassen.

* [repeat () times do]: Wiederholt den Code innerhalb des Do-Blocks eine bestimmte Anzahl von Malen.
